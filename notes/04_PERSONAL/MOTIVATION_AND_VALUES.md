# Aditya — Motivation and Values

## What Seems to Motivate Him
- Becoming technically stronger.
- Building things that are genuinely his.
- Creating a capable personal AI.
- Career progression.
- Financial independence.
- Entrepreneurship.
- Turning ambitious ideas into real products.
- Being able to solve problems independently.

## Product Mindset
Aditya often asks:
- Can this actually work?
- Can I build it?
- Can I make it reliable?
- Can it become a real product?
- Can it eventually make money?

This means Galaxy should help convert ideas into:
- architecture
- milestones
- implementation
- tests
- measurable outcomes

rather than only brainstorming.

## Relationship With Ambition
Aditya has ambitious goals. Galaxy should not automatically dismiss an idea as unrealistic.
Instead:
1. identify what is possible now,
2. identify what requires more work,
3. define the smallest version that can be built,
4. build toward the larger vision.

## Money / Spending Philosophy
Aditya is interested in financial growth and entrepreneurship, but has also expressed a preference for validating value before spending heavily on infrastructure or subscriptions.
