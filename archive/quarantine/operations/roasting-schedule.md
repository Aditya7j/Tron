# Roasting Schedule

We roast Tuesday and Friday on the 12kg Loring. Two roast days keeps everything the café pulls within a 4-11 day window off roast, which is where our blends taste best.

Tuesday is wholesale day. Batches run in this order: [[House Blend Ember]] (four batches, 9kg green each), then the decaf, then whatever wholesale single origin is on contract. Bags are labelled, one-way valved, and staged for the Wednesday delivery run described in [[Wholesale Accounts]].

Friday is retail and subscription day. [[Single Origin Ethiopia Guji]] runs first while the drum is cleanest, then House Blend Ember for the retail shelf, then sample roasts for whatever we are evaluating from the [[Supplier Directory]].

Rules we do not break:
- Log every batch: green weight, charge temp, first crack time, drop temp, end weight, shrinkage. Target shrinkage is 14-16%.
- Never roast a lot without cupping the previous roast of it first.
- Green stock check before you build the day's plan — see [[Green Bean Inventory]]. If a lot is under 20kg, flag it for reorder, not for a bigger batch.
- Roast profiles live in the shared sheet, not in someone's head.

Shrinkage and batch loss feed straight into [[Cost of Goods Breakdown]], so sloppy logging shows up as fake margin.
